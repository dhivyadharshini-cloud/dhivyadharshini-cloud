## 🚀 Featured Projects

### 🩸 [BloodLink: Emergency Blood Coordination Network](https://github.com/dhivyadharshini-cloud/bloodlink-frontend)
A MERN-stack app that closes the critical time gap between hospitals and voluntary donors.

| | |
|---|---|
| **Problem** | In emergencies, finding a matching donor fast is slow and manual |
| **Solution** | Dual portals (Hospital / Donor), emergency broadcasts, GPS tagging, live donor transit simulation with ETA |
| **Stack** | React.js · Node.js · Express.js · MongoDB · Vercel |
| **Links** | [Live Demo](https://bloodlink-frontend-eight.vercel.app) · [Frontend](https://github.com/dhivyadharshini-cloud/bloodlink-frontend) · [Backend](https://github.com/dhivyadharshini-cloud/bloodlink-backend) |

### 🦯 Blind Assist Device *(May 2025)*
A smart assistive device that detects nearby obstacles with **ultrasonic sensors** and warns visually impaired users through **vibration alerts**, supporting safer, more independent movement.
